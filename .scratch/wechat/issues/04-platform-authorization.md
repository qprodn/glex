# 04: 平台授权接入微信应用

**What to build:** 运营选定一条已经就绪的微信平台，由对方管理员完成授权。系统按微信返回的结果建立微信应用，并固定挂在这条平台上。再次授权恢复的是同一条应用。换平台、改成直连，或与已有直连撞上同一个 AppID，都留在原记录上，也不产生第二条。平台下面还有未撤回的应用时，不能撤回这条平台。

**Blocked by:** 02 — 平台验证票据与平台连通性测试；03 — 直连接入微信应用

**Status:** done

- [x] 发起平台授权时必须选定一条就绪且未撤回的微信平台；未就绪或已撤回的平台不能用来授权
- [x] 授权完成后，应用的 AppID、名称、公众号或小程序、服务号或订阅号，以及这次授予的能力，都来自微信，并挂在所选的那条平台上
- [x] 平台授权不保存对方的 AppSecret，也不提供直连那种重新生成消息推送密钥
- [x] 公众号授权没有回报服务号或订阅号时，不创建微信应用
- [x] 同一个 AppID 在同一条平台上再次授权时，恢复的仍是原来那条应用，授予的能力按微信这次的结果更新，平台绑定不变
- [x] 这个 AppID 若已经是一条未撤回的直连，或已经挂在另一条未撤回的平台上，原记录保持原样，不新建第二条
- [x] 一条应用不能从直连改成平台授权，也不能从平台授权改成直连或换到另一条平台
- [x] 一条平台下还有未撤回的授权应用时，撤回这条平台被拒绝
- [x] 平台撤回被拒绝时，已经撤回的应用仍留在历史里
- [x] 一条平台未就绪时，不能用它发起新的授权；其他已就绪平台上的应用和所有直连应用不受影响
- [x] 上述行为由微信领域服务测试覆盖，开放接口端口可脚本化，不断言微信权限集的数字编号
