# 08: 送达回写与其他推送

**What to build:** 微信事后推来的送达结果，按 msgid 写回原来那条微信下发，应用已经撤回也一样。对不上的送达、关注、文本和其他已验签的推送只被应答，不新开记录，也不自动回复。

**Blocked by:** 07 — 选用模板并发送微信下发

**Status:** ready-for-agent

- [ ] 平台回调和直连应用回调上，带有已知 msgid 的送达事件更新原来那条微信下发
- [ ] 应用已经撤回后，它的下发仍能被后续送达事件更新
- [ ] 对不上任何下发的送达事件被应答成功，不新开微信下发
- [ ] 已验签的关注、文本和其他推送被应答成功，不落库，也不自动回复
- [ ] 明文推送、兼容模式推送，以及验签失败的推送被拒绝，不改变微信应用，也不改变微信下发
- [ ] 领域服务测试把推送验签当作真实协作对象：合法的加密送达会回写下发，明文、兼容模式和坏签名不会改变状态
