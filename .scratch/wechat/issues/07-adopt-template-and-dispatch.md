# 07: 选用模板并发送微信下发

**What to build:** 运营从微信的公共模板库给一条微信应用选用模板，然后向一个 openid 同步发送一条模板消息、订阅通知或订阅消息。微信受理或拒绝都会留下一条新的微信下发。再发送一次是另一条。下发列表可以按应用查看，已撤回应用的下发还在。

**Blocked by:** 05 — 微信应用连通性测试与失效

**Status:** done

- [x] 运营可以通过这条应用当前的令牌，从微信公共模板库选用一条模板
- [x] 同一条未撤回的应用上，同一条公共模板不能选用第二次
- [x] 本系统不提供自建模板，也不实现用户在微信客户端里点订阅
- [x] 一次发送只发给一个 openid，请求等到微信受理或拒绝才结束
- [x] 还没有选用模板，或没有填写 openid 时，发送被拒绝，不产生微信下发
- [x] 微信受理后留下一条新的微信下发，带有 msgid、openid、模板、填好的内容，以及运营选填的网页 URL 和小程序页面
- [x] 网页 URL 和小程序页面都填写时，两条都记下并交给微信
- [x] 微信以业务原因拒绝（包括用户没有订阅）时，留下一条新的、没有 msgid 的拒绝下发，应用不失效
- [x] 发送超时或微信不可用时，调用失败，应用不失效，也不留下一条已受理的下发
- [x] 微信明确拒绝授权或密钥时，应用失效，并且没有一条被记成已受理的下发
- [x] 运营再次发送时，产生另一条新的微信下发
- [x] 服务号可以发送模板消息和订阅通知；小程序可以发送订阅消息。种类与应用不符时在本地拒绝，不调用微信，应用不失效
- [x] 订阅号在本地拒绝模板消息和订阅通知；平台授权缺少对应能力时同样在本地拒绝
- [x] 应用已停用、已失效、已撤回，或它挂着的平台未就绪时，选用模板和发送都被拒绝
- [x] 下发列表包含已撤回应用的下发，并可以按应用筛选；日常的应用列表仍不显示已撤回的应用
- [x] 后台出现「微信下发」。选用和发送放在微信应用详情里。权限是 `wechat:dispatch:list` 和 `wechat:dispatch:create`，并授予超级管理员
- [x] 领域服务测试通过开放接口端口区分受理、业务拒绝、超时和明确拒绝
