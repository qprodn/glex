# 03: 直连接入微信应用

**What to build:** 运营可以用直连接入一个小程序，或一个标明了服务号或订阅号的公众号。系统生成消息推送密钥，只在生成和重新生成时出示全文。应用可以停用、恢复和撤回。未撤回的微信应用之间，同一个 AppID 只有一条。

**Blocked by:** 01 — 登记微信平台

**Status:** ready-for-agent

- [ ] 运营可以直连接入小程序，填写名称、AppID 和 AppSecret
- [ ] 运营直连公众号时必须标明服务号或订阅号，否则不能创建
- [ ] 创建成功的那次响应给出消息 Token 和 EncodingAESKey 的全文；之后的查询只有掩码
- [ ] 每条直连应用向运营展示自己的回调地址
- [ ] 运营可以重新生成消息推送密钥，全文只出现在这次响应里；旧密钥立即作废，应用不因此失效
- [ ] 运营可以提交新的 AppSecret，页面和后续查询不回显明文
- [ ] 运营可以停用一条应用，之后再恢复；停用不是撤回，也不是失效
- [ ] 运营可以撤回一条直连应用；日常列表不再显示它
- [ ] 未撤回的应用之间，相同 AppID 被拒绝
- [ ] 撤回之后，同一个 AppID 可以再接入，并且是一条新记录
- [ ] 操作日志里的 AppSecret 和消息推送密钥已被擦除
- [ ] 后台出现「微信应用」。权限是 `wechat:app:list`、`create`、`update`、`remove`，并授予超级管理员
- [ ] 上述行为由微信领域服务测试覆盖，断言运营能观察到的结果，不断言 SQL 或密文字节
