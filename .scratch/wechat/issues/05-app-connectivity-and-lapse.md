# 05: 微信应用连通性测试与失效

**What to build:** 运营可以对直连应用和平台授权应用做微信连通性测试。测试不产生微信下发。微信明确拒绝授权或密钥时，这条应用失效；超时不会。停用的应用仍可测试。直连提交新密钥，或在原来的平台上重新授权，恢复的是同一条应用。

**Blocked by:** 04 — 平台授权接入微信应用

**Status:** done

- [x] 直连应用和平台授权应用都可以做微信连通性测试，测试不产生微信下发
- [x] 测试成功不改变这条应用的停用、失效和接法
- [x] 微信明确拒绝授权或直连密钥时，这条应用失效，并且没有一条被记成已受理的下发
- [x] 超时或微信不可用时，这次测试失败，应用不失效
- [x] 停用的应用仍可做连通性测试
- [x] 失效的应用在恢复之前不能做连通性测试；已撤回的应用不能测试
- [x] 给失效的直连应用提交新的 AppSecret 后，失效被清除，恢复的是同一条应用
- [x] 在原来的平台上重新授权后，失效被清除，应用仍挂在这条平台上，能力按微信最新一次授予更新
- [x] 一条平台未就绪时，挂在它上面的应用做连通性测试会失败，且不因此失效；其他平台上的应用和所有直连应用仍可测试
- [x] 后台可以发起应用连通性测试。权限是 `wechat:app:probe`
- [x] 领域服务测试通过开放接口端口区分成功、业务拒绝、超时和明确拒绝，不断言微信错误码表
