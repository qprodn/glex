# 09: 小程序登录

**What to build:** 调用方拿小程序的 AppID 和一次性登录码，换回这个微信应用下的 openid；微信若返回了 unionid，一起交还，没有则为空。直连和平台授权走同一个入口。不产生微信用户、系统用户或登录会话，也不返回 `session_key`。

**Blocked by:** 05 — 微信应用连通性测试与失效

**Status:** done

- [x] 调用方提交小程序 AppID 和一次性登录码，得到 openid
- [x] 微信返回了 unionid 时，结果里带有 unionid；微信没给时，unionid 为空
- [x] 结果里没有 `session_key`，也没有本系统的凭证
- [x] 不创建微信用户、系统用户或登录会话，也不写登录日志
- [x] 直连小程序和平台授权小程序使用同一个入口，调用方不需要说明接法
- [x] 未知 AppID、已撤回、已停用、已失效、不是小程序、平台授权没有登录能力，或所挂平台未就绪时，登录失败，且不留下任何人员记录
- [x] 微信把登录码当成业务拒绝时，登录失败，应用不失效
- [x] 微信明确拒绝授权或密钥时，应用失效
- [x] 这个入口不要求后台的登录态
- [x] 领域服务测试覆盖交还结果、空 unionid、业务拒绝和明确拒绝
