# 09 — 后台页面：支付单与退款

**What to build:** 支付单列表 / 详情页：发起支付弹窗（选商户、填业务单号 / 金额 / 主题）展示二维码并轮询状态；详情展示渠道交易号、付款方、时间线，提供手动关单与主动查询按钮（行为与后端语义一致——终态不可逆）。退款页：对 PAID 支付单发起退款（金额、原因）、展示退款状态与已退累计。金额在页面以元展示、提交以最小单位计算，换算只发生在展示边缘（ADR 0019）。细节参见 `.scratch/payment/design.md` §7。

**Blocked by:** 07 — 退款链路：多次部分退款与上限。

**Status:** ready-for-agent

- [ ] 后台发起支付 → 展示二维码 → 状态经回调或轮询自动变为已支付
- [ ] 手动关单 / 主动查询按钮与后端语义一致，终态单据上按钮不可用
- [ ] 对已支付单发起部分退款并看到退款状态推进与已退金额累计
- [ ] 列表可按状态、业务单号、商户、渠道、时间过滤
